# ToDay — The Modern To-Do List
If you want information for the CodeJam, scroll down.

## What is ToDay?
ToDay is a modern to-do list, focusing on time management! <br>
In this productivity app, you get control over a timer, and you can set your to-do tasks to lock the timer, so you can't change it freely.<br>

You don't really believe that, though, right?<br>
Of course, ToDay is really a game. Let's check out BombMode.

## BombMode
This is the main game loop.<br>
Gain points by completing tasks (+ 100 points). **Twist** the dial to increase your time, but lose 50 points every time you do so. <br>
There are also timer-locking tasks, which prevent you from twisting the dial until they are completed.<br>
Gain as many points as you can before you run out of time.<br>

Good luck, you'll need it.

## CodeJam Information
This project was made over the course of 2 weeks, with AI as a coding assistant. Everything is made by me, with the exception of the words for the Random Word, Reverse Word, and Odd One Out tasks being given by Gemini. This game is endless, and is my first major web project, with the most complex thing I'd made in HTML/CSS/JS before this being Tic-Tac-Toe. As a result, I've learned a lot throughout this project. If you decide to download this repo, it runs right out of the box.
