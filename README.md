# ToDay — The Modern To-Do List
## What is ToDay?
ToDay is a modern to-do list, focusing on time management! <br>
In this productivity app, you get control over a timer, and you can set your to-do tasks to lock the timer, so you can't change it freely.<br>

You don't really believe that, though, right?<br>
Of course, ToDay is really a game. Let's check out BombMode.

## BombMode
This is the main game loop.<br>
Gain points by completing tasks. **Twist** the dial to increase your time, but lose 50 points every time you do so. <br>
Gain as many points as you can before you run out of time.<br>

Good luck, you'll need it.
